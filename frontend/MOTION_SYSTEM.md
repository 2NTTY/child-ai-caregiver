# 育有方前端動效規範

本文件記錄 FE-W37 採納的動效方向及前端接合邊界，依據使用者確認的《育有方動態指導與實作規範》及互動示範整理。適用 `frontend/**` 的既有畫面，不新增業務動作或取代正式 Server 契約。目前工作及驗收關口見 [PLAN](PLAN.md#active)；接線差異見 [HANDOFF](HANDOFF.md#semantic-motion)。

## 體驗準則

- 全站共用精準、溫和的基本節奏；按功能語意選擇不同動作，不只是調快慢。
- 只有改變的區域播放動畫。刪除中間項目後，位置確實改變的存續列平順補位，上方未受影響列保持不動。
- 03 使用完整柔色幕布，不增加細線掃場。幕布遮滿時切換底下的呈現內容，再揭開；不能等幕布離開後才更新文字。
- 普通孩子切換幕布不立即顯示「正在切換孩子」；同一次有效遮蔽持續逾 5 秒才顯示文字與柔和活動提示，揭開／取消／離頁／換範圍即清除。減少動畫不播放活動動畫；沒有實際業務 hold 時不製造假的載入等待或以動畫冒充成功。
- 只有前後均為有效且不同孩子才視為切換；首次無孩子到首個孩子、相同孩子或身份初始化不播放切換幕布。切換孩子是範圍切換，使用內容窗格的幕布。新的孩子標示不可配上舊孩子的可讀內容；失權、登出及清理優先於動畫。
- 同一元件保持穩定身分。不能用改 key、重掛整頁或重建整張清單，製造不必要的再次進場。
- 動畫只管理呈現，不延後權威資料操作，不把動畫完成當成保存、接受、通知送達或查核成功。

## 呈現容器與首屏

以下是使用者確認的要求，不能單憑實作存在就標為已驗收。

- 灰色遮罩統一由 `MotionBackdrop` 管理顏色、透明度、進場及減少動畫；獨立灰幕沿右側欄共用 240 ms 進場及曲線，中間提示框保留原本 220 ms 節奏，兩者同時開始、錯開完成，操作與焦點不等待灰幕；各浮層不另寫灰幕或疊加 vendor 灰幕。抽屜傳入既有共用進度以同步進退。RN Modal 類關閉仍立即釋放焦點與互動，現階段不把延後關閉當作退出淡出的替代；這個平台生命週期限制須在交付中明列。
- 寬版資訊欄的佔位寬度與欄面位移共用同一進度，主內容連續讓位而非被遮蓋；窄屏覆蓋欄從右往左進場，反向退出，灰幕同步淡入／淡出。關閉立即釋放互動與焦點，不等待視覺退出。原生平台限制另列，不以 Web 結果代替。
- 第一個可見布局須用實際內容容器的寬度與正確初值。設定、記憶及其他同型頁面按共用方法修正，不先畫錯誤欄數再用動畫掩飾。路由及局部分頁保持內容可見，不用整面透明造成白閃。
- 首屏亦須等待目前身份／孩子及當頁必要資料到達可呈現狀態；正式頁面共用既有 owner，不另外保存資料副本。明確錯誤或離線讓既有重試介面可達，不能用總遮罩吞掉。首次登入／身份世代切換重新判定，普通刷新及導航不反覆全站封鎖。
- 載入文字的三點依序輕跳，只用 transform 保持布局穩定，螢幕閱讀器只讀固定載入文字；系統減少動態時保持靜態。動畫不決定業務是否完成，卸載／取消必須清理。
- 首屏必要插畫完成載入／可用解碼及布局後才揭示；失敗或超出有界等待時使用確定後備，不能當成載入成功，也不讓晚到圖片突然補現。只等待當前首屏所需資產，後續導航不重新封鎖；手機問候計時由揭示後開始。
- 手機頂欄的孩子／資料列在原有 Logo 槽內由左往右取代品牌標誌，保留原頂欄高度及鈴鐺／資訊側欄控制；離開相關頁面時反向還原。取消額外一列的上下展收及正文下推。窄寬度沿共用橫向內容提示揭示資料，不壓縮必要操作、不另外保留隱形垂直佔位；減少動畫直接切至有效終態。這是 2026-10-04 最新呈現決定，取代較早的手機資料列展開／收起要求。
- 同類橫向選項復用右邊「尚有內容」箭頭。箭頭有獨立位置，不蓋標籤；末端隱藏，全部放得下則不留空槽。保留觸控、鍵盤及選中項揭示，尺寸／內容變化時重新量測。

## 幕布生命週期

1. caller 保留業務操作身分、目前範圍及狀態，明確標示手動更新意圖。
2. pending 期間不假造成功或反覆播放幕布。新結果有效且語意內容有變，才進入遮入階段。
3. 遮滿時提交唯讀呈現的新資料，確認 React 布局提交後才開始揭開。
4. 同內容的已完成操作消耗該次意圖，不讓往後背景刷新誤用它。失敗、unknown、取消或範圍失效清除未消耗意圖。
5. 快速連按只保留最新有效呈現；過期回呼不能換入舊資料或重新建立幕布。

`contentKey` 以實際顯示內容與版本計算，不以物件參考、任意時間戳或整個 view model 的序列化代替。`scopeKey` 應覆蓋相關身份、孩子、權限或實體範圍。每個區域獨立清理，不為更新摘要而取消另一個獨立浮層。

幕布內只保留唯讀投影，不能複製秘密欄位、互動表單或整棵路由。照片的候選揭示不代表已保存；採用候選若只是填入草稿，亦不代表正式確認。

## 清單與狀態保留

- 使用穩定實體 ID 作 key。家庭成員的整體版本不能令全部成員重掛；但既有 epoch／resetCounts 若是身份、失權或草稿清理契約，不可機械移除。
- 退出列保留短暫視覺空間，先量測存續列的位置；真正移除後在同一座標系量測新位置，再僅對差值非零的列反向位移並播放到 0。
- 焦點在退出列時，依序移到合理的下一列、上一列或清單入口；其他列的焦點、文字選取及草稿不主動移動。
- 已確認更正保留原已載入前綴；新增僅在既有排序確實插入前綴時擴展一筆；刪除僅移除前綴中的該筆，不重設首個分頁或補入未載入資料。明確重新查詢、篩選或範圍切換仍沿原重設契約。
- 詳情中的刪除確認完成後，桌面與窄屏均恢復到有效存續列或清單入口；以實際 activeElement 驗證，普通資料重繪不得取消返回焦點回呼。
- 有限清單暫時沒有某項目，不代表該業務實體已刪除。分頁、篩選、背景讀取與已確認刪除的觸發條件分開處理。
- tasks 的既有操作為建立、改期、指派、完成、取消與終態覆核；本包不新增待辦改名或刪除 API。示範的動態語意依實際業務操作套用。

## 不受動畫影響的行為

- 引用定位與返回引用句立即完成，保留現有可見焦點回饋及來源箭嘴；引用正文不整段滑動。
- 中文輸入、游標、文字選取、聊天跟隨意圖與未發送草稿保留。真串流不加假打字，不反覆動畫同一訊息。
- unknown 查原操作、版本衝突、撤權、秘密清理及候選確認繼續由既有控制器處理。
- Paper Switch 等已有合適動態的成熟控件沿用既有能力，不再加第二層動態。
- 錯誤訊息與重要狀態立即可達，不靠顏色或動畫單獨傳達。

## 減少動畫及中斷

設定 → 應用偏好提供「減少動畫」Paper Switch。有效偏好為系統要求 OR 使用者手動啟用；關閉手動開關只恢復跟隨系統，不能強行覆蓋系統要求。Web 以本機 localStorage 保存單一偏好並同步同來源頁面；儲存失敗時退回本次 session 並提示。原生目前僅 session，未接持久儲存。共用工作區、手機首頁及舊動效比較頁都遵守有效偏好。

系統減少動畫優先。啟用時保留所有資訊及焦點流程，立即到有效終態；不播放幕布、推移、補位或進場。播放途中變更設定、換範圍、離頁、尺寸改變或卸載，都須清除遮罩、固定高度、transform 與失效回呼。取消呈現不等於取消伺服器操作。

Web 及原生使用各自可用的偏好與布局能力；bundle 成功不能取代真機、系統鍵盤或讀屏驗收。

## 接合與驗收邊界

本包沿用 Expo／React Native／Paper 及既有資料模型。共用呈現能力放 `src/motion/`；畫面只提供資料、語意 key、範圍與明確觸發，不另建業務狀態機。所有正式 API、根目錄 App／client、Server、通知及雲端部署維持原分工。


驗收需觀測動畫中間幀及終態，不能只看前後截圖。重點是幕布交接、孩子範圍一致性、單項退出與受影響列補位、焦點／草稿保留、減少動畫及快速取消。實際命令、次數、失敗與未驗項另按本包證據記錄。
