# 育伴港前端狀態

更新：2026-09-26。本文件只記 frontend/**；根目錄 [STATUS](../STATUS.md) 才是產品、Server 和正式 App 的進度。

| 工作包 | 狀態 | 前端現況 | 尚待事項 |
|---|---|---|---|
| FE-W01 Web 主頁基線 | 待使用者視覺驗收 | 隔離 Expo Web 預覽、共用主題／元件、合成資料與首頁已交付 | 使用者比較；正式接線由主聊天另行整合 |
| FE-W02 Web 共用框架與核心畫面 | 待使用者視覺驗收 | 八個 Web 路由與共用外殼、可關閉右資訊欄、左下設定／用戶、手機瀏覽器重排及本地互動已實作；typecheck、Web build、預覽瀏覽器檢查通過 | 使用者比較視覺與流程；正式 API、登入會話、權限與保存收據待主聊天接線及真服務驗收 |
| Android 前端 | 未開始 | 無 Android App 實作或真機證據 | 整套 Web 經使用者明確確認後另立計劃 |

FE-W02 的畫面資料、孩子、家長、記錄與操作狀態均為合成預覽；沒有向 Server 發送請求。正式 P1／P2 可用範圍及未接通項目見 [HANDOFF](HANDOFF.md) 與根目錄 [P2 UI 清單](../docs/P2_UI_HANDOFF.md)。Web 前端畫面可供比較，不等於正式產品接線完成。
