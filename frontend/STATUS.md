FE-W01 至 FE-W05 的畫面資料、孩子、家長、記錄、待辦與操作狀態均為合成預覽；沒有向 Server 發送請求。FE-W05 動態只是[選型樣本](MOTION_OPTIONS.md)，未改其他頁面。正式 P1／P2 可用範圍及此 Web 預覽仍缺的介面見 [HANDOFF](HANDOFF.md) 與根目錄 [P2 UI 清單](../docs/P2_UI_HANDOFF.md)。Web 前端畫面可供比較，不等於正式產品接線完成。

FE-W01 至 FE-W04 的源碼已按工作包隨 PR #40–#43 合併，但視覺驗收與正式接線仍未完成。使用者決定先繼續後端，前端後續暫停至另行提出；再開包時優先補已有契約的照顧記錄搜尋／更正與子女檔案結構化細節，任務和通知正式流程仍等各自業務契約。
