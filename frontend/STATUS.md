# 育伴港前端狀態

更新：2026-09-26。這份文件只記錄 `frontend/**` 的獨立前端工作包；產品、Server 及正式 App 的進度仍以根目錄 [STATUS.md](../STATUS.md) 和 [PLAN.md](../PLAN.md) 為準。

| 工作包 | 狀態 | 現況 | 尚待事項 |
|---|---|---|---|
| FE-W01 Web 主頁 | 待驗收 | 依 1586×992 參考圖重排桌面首頁；隔離 Expo Web 預覽、共用主題／元件、合成狀態切換及響應式畫面已實作；typecheck、Web build、鍵盤與互動檢查通過 | 使用者比較視覺與流程；正式 API 接線由主聊天另行整合及驗收 |
| 後續 Web 畫面 | 未開始 | 依使用者下一張參考圖逐包指定 | 不因 FE-W01 完成而自動開包 |
| Android 前端 | 未開始 | 尚無 Android 實作或真機驗收 | 整套 Web 完成並獲使用者明確確認後才另立計劃 |

FE-W01 畫面資料、操作收據、孩子與家長名字全部是合成預覽；`frontend/` 沒有呼叫 Server。現網 P1 與 repo 內 P2 的可用範圍須按根目錄狀態及 [P2 UI 清單](../docs/P2_UI_HANDOFF.md) 判斷，不能從這個畫面推斷已部署或已接線。

預覽入口、驗證證據及主聊天接線條件見 [HANDOFF.md](HANDOFF.md)。
