# 育有方 Web／手機設計規則

<a id="user-first-principles"></a>
## 產品目的與設計取捨

2026-10-05 使用者確認：讓家長以最少心力完成育伴港最重要的事。以下是已採納的判斷原則，並非新增功能清單或已完成聲稱；具體產品契約仍依 SPEC，實作／未驗狀態依 [PLAN](PLAN.md#active)。

1. **從家長任務出發**：理想主流程是「跟 Agent 說 → Agent 組織記錄 → 家長看重點、必要時確認」。手動輸入承接例外，不把整理資料的工作重新交回家長。
2. **核心功能保持突出**：全站聚焦家長與 Agent 的照護交代及結果，每頁有明確主要任務；單人核心流程不要求先建立家庭或邀請成員，既有協作能力保留。畫面以家長能理解及使用的整理結果為中心，不把資料庫表或管理欄位直接堆成頁面；報告先呈現重點與依據。
3. **常用功能容易到達**：按使用頻率、重要性及情境安排入口，常用且低風險的操作就近直達，避免入口再套入口；低頻細節按需展開。
4. **共用有適用邊界**：共用行為、語義、可及性及 tokens，再按操作角色、內容密度與 viewport 組合版型；不以組件復用率或全站外觀相同作成果。桌面與手機可有不同佈局，任務及資料含義保持一致。
5. **重點一眼可讀**：層級、間距、尺寸及主次比例服務掃讀；留白有用途，內容不擠成團，次要工具不搶正文。判斷完整畫面的閱讀焦點，不能只看沒有溢出。
6. **減少認知負擔**：家長看得懂「這是甚麼、目前到哪裏、接下來做甚麼」。文字、圖示及狀態可辨認，避免重複入口、隱晦圖示或要求記住操作位置。
7. **操作成本配合風險**：普通低風險操作順手完成；危險或高影響操作核對具名對象及影響範圍。可恢復的操作提供符合契約的撤銷／恢復，不用多一層確認取代可逆性，亦不為少點一下而省略必要保護。
8. **資料一致且值得信任**：同一權威來源供不同頁面投影，家長能核對 Agent 的理解、來源和待確認內容。已記錄、已確認、已保存、已通知及未知各有證據邊界，不能因視覺簡化混為一談。

P2 增補沿用以下呈現，不改版型／美術；準備單是一次具體事情到時可用的行動資料，待辦是何時做甚麼。產品定義見 [SPEC](../SPEC.md#req-p2a-08)，工作包只見 [根 PLAN](../PLAN.md#p2-agent-service)，不在設計文件另存一份計劃。

具體頁面責任見[功能版型](#function-specific-layouts)，控制項適用範圍見[操作角色](#control-roles)；實作決策、反例及驗收方法只維護於 [Web 畫面 Skill](.agents/skills/web-screen-delivery/SKILL.md#decision-routing)。

## 共用視覺語言，按功能安排版型

### 2026-10-23 統一美感，不統一內容外殼

使用者確認：統一的是視覺美感、資訊及操作的位置邏輯、主次、對齊、間距與互動品質，不是讓每頁套同一張外卡、相同比例或相同內容順序。本節釐清下方配方的共用邊界；屬已採納設計方向，不表示全站已重設計或完成驗收。

- **按家長目的設計專屬結構**：先決定家長來這頁看甚麼、做甚麼，再安排資訊模組、卡片／列表、閱讀比例及主要操作。對話、待辦、核對、時間線、文件與設定可以各有形態；已有合適版型便保留，不為不同而不同，也不只靠換圓角或顏色製造「專屬」。
- **共用品質，不鎖死形狀**：沿既有語義色、間距尺度、控制項、鍵盤／觸控及狀態規則；同角色的位置與對齊可預期。卡片可長方、可按內容自然延伸，只有用途需要才分欄，不強制正方形、固定長寬比或全站同款列表。共用導航及背景承托不決定內文必須使用同一外殼。
- **文字按角色選擇**：標題、正文、工具與次級資訊可使用各自合適的字體、字重及字級；相同角色保持可預期層級，不把「統一」理解成所有文字同一字體。仍沿既有字體來源、可讀性及系統縮放規則，不因此新增外站字體載入。
- **本輪頁型例子**：歷史的「待辦與預約」逐行單欄，方便順序掃讀；核對的待確認內容保留現有獨立方塊，不改成同款列表，也不強制 1:1；核對的已保存記錄用事件內容優先的長方卡，種類與時間居次，確認時間不可冒充事件時間。其他歷史分類繼續沿其原領域內容及閱讀入口，不隨待辦一併改版。
- **薄前端與誠實狀態不變**：版序及美感不能靠補造業務判定完成；不以孩子數量、頁面瀏覽或本地旗標推斷引導已完成。來源、權限、風險、未確定及原操作恢復資訊仍須保留，資料含義沿權威 owner／契約，不為排版新增第二份業務狀態。

選頁型前先問：家長此刻要看／做甚麼？第一眼應見哪段內容及哪個動作？現有模組是否已合用，最小調整能改善甚麼？這次改動是否仍保留來源、狀態、操作守衛及窄屏／鍵盤可用性？實作與驗收按實際變更範圍另記，不由設計原則推定通過。

### 2026-10-21 精簡版覆核

以下為該輪使用者確認的覆蓋；下方 FE-W 歷史配方不再覆蓋這些值，頁型共用邊界依上方 2026-10-23 原則。

- 導航使用短名，`/growth` 為「關注」（關注鏈／準備單），`/summary` 為「概況」（概況／成長檔案）；手機五格保留，原成長位置改關注。「全部功能」是兩字規則的明確例外；記錄手勢短提示為「上拉更多」，目的地仍是全部功能。孩子入口只保留頭像／姓名／選擇，不另加「檔案已確認」標籤，不重複年齡、地區及過敏資料。
- Agent-first、閱讀優先：普通資料手動新增／編輯／核對放次要入口，沿共用 FormDialog 進入；長表單可捲動，欄位與同類動作整齊對齊。登入、搜尋及權限設定不因此一律變成彈窗。關閉／返回／Escape 均先沿原草稿／原操作守衛；確認、查核與原內容重試在窗內可達，不能以卸載冒充取消。檔案直接閱讀已確認值，不重複孩子切換列。
- 聊天正文 16／27、閱讀欄上限 760；助手仍為連續正文，使用者以 quietSurface 輕底區分，品牌黃色保留於送出等主操作。多行輸入與工具同一 dock，左側附件／相機，右側語音／送出；建議僅在空對話按需展開。狀態一行呈現但不能藏失敗、未知或待確認；不增加沒有接線的分享／重生成。讀歷史不被新訊息拉底，送出後焦點依明確請求一次恢復，不在忙碌結束時搶焦點。
- 記錄頁長助手運行採真實摘要及「查看結果」閱讀窗，原結果、來源、候選、確認與恢復沿同一 owner；聊天正常答案保持直露。沒有讀回／無權限與讀取中分開，不以清單摘要代替可提交原提案。
- 正常日期時間到分鐘，不逐條顯示時區後綴；實際香港／事項明確時區換算、原 timestamp、分頁游標及排程時區選擇不改。使用者頁不呈現通知投遞技術細節，診斷記錄仍留原後端。
- 自訂背景只在首頁持續顯示，不隨問候收起；設定提供真實縮略效果及恢復預設。閱讀區用平整實底、照片在留白可見，不疊巨大圓角外卡；不鋪登入／導航／彈窗。圖片本機持久、按服務及本人隔離，登出立即遮罩，不上傳或交模型。問候只有首屏就緒及可見後才開始既有閱讀時間；初始化不消耗播放，減少動態沿 MOTION_SYSTEM 的即時終態。
- 設定保留原八個路由 key，顯示帳戶／孩子／家庭／外觀／通知／助手／模型／私隱；通知偏好與渠道同區，原 dirty／保存／unknown 邊界不變。登入重寄驗證左、忘記密碼右，同一輕量列；錯誤與必要註冊條件保留。
- 頂條 attention、首頁重要提醒及通知正文收件箱仍欠語義 API，不能由多個頁內 owner 拼業務計數或以假空態冒充接線；分工見 [接口交接](ATTENTION_API_HANDOFF.md)。


沿[產品目的](#user-first-principles)安排各頁責任及密度；共用基礎元件，不強制重用整頁結構。以下保留各功能已確認的版型，未接通能力仍按原交接界線處理。

- **今日**：第一眼看整體及關鍵事項；突出少數重要提醒和持續關注摘要，不完整複製清單／表單，也不以假內容填空；提醒原因以輕量「為甚麼提醒我？」預設收起重複說明，必要來源與時間可查。永久正文以緊湊「今日＋日期」開始，重點卡用黃色左側強調及明確主操作，持續關注用輕量資料列。歡迎不是常駐大型 hero：只在本次登入首次進入時短暫出現，再平順向上退出，返回首頁不重播；問候用「你好」，不預設照顧者是媽媽。桌面歡迎橫幅限制閱讀寬度並平衡插畫比例，不把文字和小圖拆在超寬兩端；手機獨立內距。首頁不能依賴已收起的正文卡提供孩子切換，窄版各頁沿同一固定 64px 頂欄入口。文字主次及右側插畫整體平衡，完整保留人物頭部。合成預覽的 session 旗標不冒稱正式登入契約。
- **助手**：以對話正文與輸入為中心，沿 [ChatGPT 官方產品介面](https://chatgpt.com/overview/) 的清楚主次：使用者右側泡泡、助手左側正文、限寬訊息與底部輸入。空白對話只放一句簡短起聊提示，不把正常讀取數量、最後讀取時間或重複空白說明塞在輸入框上方。工具列在時間線之外；只有確有更早資料才顯示較早對話入口。運行／候選在按需詳情，自動記錄授權與私人備註在助手設定；必要確認、原操作恢復及錯誤不可因收合丟失。
- **待辦**：家長在對話中交代事項，Agent 整理安排並按授權主動提醒；本頁供查看、改期、取消和回報完成，手動新增為次要入口。頂部用「待處理／已完成」底線分頁；日期按明確的參考時間與事項時區分組，採「今日 · 月日」、後續日期等可讀形式。只有真正缺少排期的來源才可標「待安排」，不能拿無效日期或待覆核代替。已完成只列按可靠完成時間倒序的最近 10 項，不混入取消，亦不刪除更早資料；完整歷史另頁。時間、負責人、提醒安排與事項狀態分清；不得以 worker 已處理冒稱已通知家長。已選清單列再次點按可關閉詳情，但不能繞過草稿及 unknown 保護。
- **成長與關注**：2026-10-05 12:04 UTC 使用者明確分成兩頁：預設「持續關注」，以當前關注索引及逐項時間線串起起因、觀察、建議、行動與回報，已結束仍可追溯；第二頁「成長檔案」由 Agent 持續整理，直接閱讀同源標準網頁報告，年度／季度作次要回看入口。Web 關注頁索引／時間線並排，手機緊湊選擇後看同一時間線；檔案頁採閱讀版型。不得把關注藏在檔案底部，亦不把關注操作當能力達標。PDF 只導出當時版本，不能取代網頁正文；來源、權限、版本及接線需求見 [成長交接](GROWTH_HANDOFF.md#living-growth-archive)。新結構與正式生成／匯出狀態只看 PLAN，不從設計推定已完成。
- **記錄與核對**：沿底線分頁區分待確認與已保存，卡片依上方頁型原則，不一律套待辦列表；集中處理 Agent 變更，只用一個待確認計數，重要項優先，普通已記錄方便回看。直接呈現實際內容摘要，點開保留原話／Agent 理解／更新前後對照；桌面列表旁看詳情，兩欄保持清楚主次比例；手機詳情依原話／Agent 理解的自然高度閱讀，返回保留位置。來源／狀態篩選收緊，不以開發狀態填滿首屏。主頁移除「核對歷史」「其他記錄入口」兩個工具列按鈕，歷史資料與獨立歷史路由仍保留；重要待確認不因翻頁或過期消失。日常跟 Agent 說、再查看，必要更正從內容詳情就近處理，不能變成填表入口集合。正式權威接線見 [核對需求](HANDOFF.md#conversation-change-review)。

- **歷史**：獨立畫面，按事項、照顧記錄、對話、成長檔案、通知等資料類別搜尋與時間篩選；各頁「查看完整歷史」帶到對應分類。只投影原資料 owner，不另存副本；未接通分類、部分已載入資料與完整歷史明確區分。分類不是把其他整頁藏進新入口，須有一致查找用途與可回到原物件的脈絡。各分類標題下沿同一副文字位置與字體；關注與成長使用「查看已結束的關注與跟進記錄」，不增加列表行的來源聲明。

其餘頁面沿自己的功能安排，不把五個主入口的版型複製過去：

- **家庭／聯絡**：成員、負責人及授權邊界先於長表單；個人聯絡同意、渠道狀態與單次執行結果分開。
- **孩子概況／準備**：概況集中目前孩子資料、量度及興趣／偏好，保留原值、來源與未知；準備單按到診、入學、外出或照顧交接呈現重點／問題／清單，手機打開即可閱讀，用完個別歸檔到歷史。準備單列表先於操作與說明，查看歸檔、用途選擇及準備下一份放在列表後；正常預覽限制收進底部預設收合工具，不用重複標語佔首屏。不是期間數字回顧或預設整欄表單；正常頁不再顯示舊共享準備原操作查核入口；原操作恢復的相容深連結與安全守衛保留。記憶工作區繼續核對已確認事實、候選與來源，不混同成長關注。
- **設定**：桌面分類索引配單一內容欄；窄屏真正 Tabs，內容保持掛載以保護草稿，模型秘密仍在離開分類時清理。各區保存邊界明確，不以整頁外觀暗示一鍵全部保存。
- **孩子檔案／私人來源**：檔案先呈現身份及已確認重點，再分組更正；來源先呈現集合，再進同一整理與確認流程，來源用途、可信度、正式接入狀態不可混用。
- **引導／登入**：引導按當前步驟閱讀，不用假完成率；登入聚焦品牌與表單，桌面插畫／表單比例 56／44，窄屏優先表單，合成驗證不代表建立正式登入狀態。

共用外殼保留已確認安排：Web 助手固定於左下角；手機右上角維持資訊側欄，承載待辦／提醒摘要與當前孩子或關注的上下文。Web 右側資訊欄可常駐並讓主內容讓位，手機維持覆蓋式由右向左；不把完整表單或所有設定堆進側欄。臨時記錄的拍照／補一句入口須順手可達，先交代再整理。

照片入口按已確認方向收進「記錄」的照片篩選及原始附件檢視，拍照交給助手仍為快捷操作；接線安排見 [照片交接](PHOTOS_HANDOFF.md#records-photo-entry)。使用者已通知按此方向實施；實作／驗收狀態只沿 [PLAN](PLAN.md#active)，既有路由須保留相容入口。

手機快速記錄依 2026-10-06 最新要求，以水滴表面張力的平滑內凹曲線黏附內容區左緣及底緣。原 56×56 操作範圍與相機圖示保留，72×72 的延伸 SVG 只作裝飾、不接收 pointer；底緣只到導航上方，保留導航及系統安全區，不擴張透明攔截區。長按／拖曳／鍵盤展開沿原有方向選單，平時不增加整排背景或說明。

手機底部導航須持續顯示目前頁面：淺青選中面配短頂線，與短暫按壓回饋分開。一般入口與記錄入口均提供正確 selected／aria-current；不以僅有相近字色表示目前位置，亦不改原路由、上拉更多或離頁守衛。

手機「記錄」向上拖可開原有更多頁；左下快捷輸入的最新手勢、附件與選填文字規則見 [助手交接](AGENT_HANDOFF.md#mobile-quick-input-design)。手勢須有可見及鍵盤替代操作，不以動畫或拖曳作唯一入口。

Web「更多」是次要分類目錄，按實際正文寬度兩／三欄，極窄正文回退單欄；不將手機長清單及全寬返回鈕直接拉大。Web 左下只保留助手及設定，不常駐說明／引導。手機保留更多清單及記錄上滑入口，沿底部既有記錄導航，不在更多頁重複放返回記錄按鈕；其他詳情返回入口仍保留。重開引導統一到設定。首次登入或基本資料未齊時，首頁顯著顯示持續引導入口，已完成才隱藏；狀態未知不推斷完成，也不依賴短暫歡迎動畫。正式完成狀態沿權威 adapter，合成 guideStatus 不替代後端契約。

五項是功能責任與手機導航方向，不強制 Web 只有五個按鈕。Web 可分組展開高頻子功能；低頻權限／來源／通知等由設定管理。具體導航重分類仍須按已確認工作包實施，本文不把討論方案當已完成路由變更。不同入口的同一資料由同一授權來源投影；詳情可互相直達，不另維護副本。

身份：本域已採納的呈現規範；數值以實際 theme／元件為落點。包狀態／驗收見 [PLAN](PLAN.md#active)，研究理由按下方專題引用，不在此追加交付流水帳。

本版綜合主頁、Agent 對話、設定及登入參考圖；圖片只決定視覺與組件細節，產品語義仍以根目錄 [SPEC](../SPEC.md) 和 [P2 UI 清單](../docs/P2_UI_HANDOFF.md) 為準。畫面沿用項目 Logo、香港海旁美術及香港繁體中文，不照搬參考圖的嫩芽標誌、人物或虛構數據。

## 資料狀態與簡潔文案

2026-10-07 使用者確認：家長要快速看懂孩子目前情況，狀態表達一次即可；系統應正確處理資料語義，不把內部規則反覆解釋給家長。

- 有資料先呈現正文，種類、時間等 metadata 居次，必要狀態仍清楚可見；移除 Server／API 等開發用語和重複來源標籤。真實來源、未確認及會影響理解的限制仍按需保留。
- metadata 優先用語義清楚的圖標配短值，不重複可辨認的欄位名稱；含義仍不清楚時保留短 label，無障礙名稱保留完整語義。位置與組合沿[各頁專屬版型](#function-specific-layouts)，不套全站同款資料卡。
- 成功讀取後確實為空，只保留具名短句，例如「暫無興趣與生活偏好資料」。未提供／未知已表達缺項，不再補「未知不代表沒有過敏」等同義聲明。業務資料仍區分 unknown 與 none，不因刪文案改值。不影響理解的空選填欄位可在閱讀頁省略；確認／比較仍須明示相關空值，不能隱去刪除或未提供。
- 未接通／暫不可用不可假作沒有資料；每個受影響區域一個短狀態即可。篩選結果為空須保留解除篩選，未成功讀取不可呈現成功空頁。
- 同身份及孩子已有資料時，自動／手動刷新保留原位內容並安靜更新，不反覆出現全區載入或成功重讀聲明。首次慢讀及失敗才顯示必要狀態／重試；失權、資料失效及切換孩子仍立即清理不可用資料。
- 正常頁面不常駐重讀按钮、教學長段或泛化防禦聲明。實際失敗就近說明問題與可做的操作；確認、刪除、分享等後果在操作當下清楚提示，unknown 操作仍有核對入口，不為視覺簡化隱去。
- 私人範圍的短標籤用「本人」，不寫「只限你本人」。

## 操作角色與狀態辨識

正常畫面只說家長當下需要知道或處理的事。每區同一狀態只呈現一次：有「正在讀取」就不再附「尚未確認、不能當作沒有」；正常空白不解釋 Server、owner、作用域或快照。標題、badge、正文和頁腳不重述同一句意思，正文只補充必要對象、結果或下一步。

實際讀取失敗、部分／過期資料、未保存、權限、unknown 原操作及重要確認仍須就地以短句呈現；只在條件成立時顯示，配有效重試或相關入口。安全機制留在程式，必要風險告知留在相關操作，不以常駐否定句證明程式有防護。共享、刪除、模型外送／費用及具體健康資料未知等關鍵含義不可因精簡而省略。無真實接點保持不可用與短提示，不能改成零項或成功。

正式操作不可再標「模擬／合成」，已接通能力不可保留舊的「尚未提供」說明；提交前內容預覽仍可叫預覽。真正開發工具只在開發情境出現。可視狀態與讀屏名稱一致，刪掉重複正文不等於取消無障礙播報。

先辨識角色，再選共用配方。2026-10-05 已確認的實色／描邊規則適用於需要獨立視覺重量的主要／次要操作；透明工具、disclosure 及導航按下列角色處理，不再以全站二選一後逐項追加例外。

| 角色 | 適用情境與呈現 |
|---|---|
| 主要操作 | 當前任務的主要下一步、Agent 送出或必要最終確認。使用實色及對比文字，不疊常駐裝飾外框；危險語義只給實際危險操作，不把普通主操作染成警告色 |
| 次要操作 | 需要獨立可見邊界的替代操作。採清楚描邊，背景貼合所在表面，不再疊淺青／淺紅填色；不能因「次要」便藏入多重入口 |
| 輕量工具 | 來源橫向捲動箭嘴、聊天輸入工具等貼近內容的低視覺重量控制。可透明且無常態框，圖示／文字仍可辨認，保留命中範圍、按壓、hover、focus 與停用回饋 |
| 展開／收合（disclosure） | 就近揭示同一內容的補充、版本、提醒原因或詳情。用箭嘴、文字及展開狀態建立關聯，可用輕量形式，不機械套次要按鈕框；不藏起完成核心任務必讀的內容 |
| 導航（navigation） | 頁面、分類、內文來源及詳情往返。沿各自連結／分頁／導覽列的語義及目前位置提示；不因能點擊便全部包成表單按鈕，返回保留合理閱讀脈絡 |

正常狀態須可辨認操作，不靠 hover 才出現；停用保留可讀文案及相應角色。metadata 只有真實操作或可到達目的地才呈現互動，純資訊不做成假按鈕／連結。鍵盤焦點框是暫時的可及性回饋，須保留。Hover 提示提供鍵盤等效，必需資訊不能只藏在提示。數量用獨立小徽章，不當程度或危險等級；種類用圖標／短值，不混用狀態 badge。狀態用文字配語義色及適量圖示，成功／已完成、待核對／未知、失敗及一般資訊各自分清，不單靠顏色傳意。渠道接受不等於送達、已讀或事項完成。

## 手機參考圖的組件排列

首頁動畫的結尾沿同一容器定位及文字 flex；完成時只收斂 intro 和可讀狀態，不改另一套排版或移除問候子樹。外框淡出與孩子內容分開。逐幀覆核必須包含末幀寬／高及完成後的穩定性，不能只比較箭嘴位置。

2026-09-29 的手機圖採單欄、柔和卡片、大而清楚的問候及孩子切換入口。2026-10-02 使用者要求首頁減量，移除膠囊提問及問題捷徑；左側孩子資料直接開原選單，不另放右側切換按鈕或卡片日期。同一登入會話只在首次進入首頁展示問候及下方孩子卡片約 3 秒，再以 360 ms 上移孩子選擇區取代文字；右側完整圖片保持位置，今日重點、待辦、快速記錄及內容卡片跟隨自然高度。切頁返回、切孩子及桌面／手機斷點重掛載均直接顯示已上移版式，播放記錄由會話上層保留，不依首頁掛載次數。閱讀期間開啟孩子選單時暫停；開始移動後點開則收斂至最終位置，關閉不回跳。減少動態效果時保留閱讀時間後直接切換；離頁取消未完成計時和動畫並保留最終版式。首頁孩子入口使用 48 頭像、18／14 名字及年齡、至少 72 高度，動畫後文字按內容收窄，20 SVG 箭嘴與文字相距 8；開啟不添加白色長條背景，按下以局部表面微幅變深回饋，名字、圖示及邊界保持清楚，不隨按壓淡出。其他介面的動效只沿已採納的 MOTION_SYSTEM 範圍。對話沿底部助手入口進入；手機五個主要入口及「更多」的開啟方式沿[現行功能版型](#function-specific-layouts)，不恢復舊的四入口加更多分頁，也不把桌面側欄縮小塞入手機。

2026-10-03 補充：只把手機首頁的問候／副句／標語放大至 26／16／14（行高 34／24／22），桌面字體不變。孩子外框與箭嘴跟隨同一容器收窄上移，外框在移動進度 20%–60% 淡出，不隱藏孩子資訊；終態按內容自然寬度、最多 62%，避免放大字體被初始量度壓窄。3 秒閱讀及每會話一次播放沿用。

## 表單與互動一致性

重要表單使用 RHF／Zod，錯誤放在欄位旁，原文不經 trim 或數值轉換覆寫。日期本身不轉成 UTC；時刻由明確 IANA 時區換算，無效或 DST 重複／不存在時間須要求使用者釐清。小於 360 的時間彈窗採同一 Paper Dates 公開鍵盤控件，避免其標準 328 px 時鐘溢出。

有浮動標籤的多行 AppTextField 透過 Paper 5.x 公開 contentStyle 留出標籤空間，原文捲動在其下方；不關閉字體伸縮、不修改套件。390／320 的 150% Web 文字檢查須包含實際標籤／輸入區幾何與畫面，單看控制邊界不足以確認重疊；證據見 FE-W14，Android 系統大字體仍待驗。

Dialog 採 Paper 視覺配 RN Modal 的焦點／返回鍵行為；選單及勾選用共同封裝提供 Web 明確 ARIA。刪檔案、刪單筆記錄與刪整位孩子各有範圍提示及再次確認；確認結果前保留資料，unknown 鎖定並查原操作，版本改變先比較再重新核對。

FE-W22：不可恢復操作的最後提交用 AppButton `variant="danger"`，沿 errorInk／white；刪除 Dialog 用 `danger` 和 `Title danger`，白色表面、紅色邊框／標題，內容仍清楚可讀。單筆記錄／檔案／事實保留既有頁內核對，不為同一操作再疊彈窗；整位孩子的高影響刪除用 AppDialog，輸入完整稱呼及勾選範圍才啟用按鈕。風險分層參考 [Carbon Remove](https://carbondesignsystem.com/community/patterns/remove-pattern/)，2026-10-01 已核對。稱呼與勾選只防誤操作，不能代替 Server 身份重新驗證；缺口見 [交接](HANDOFF.md#toolbar-delete-safeguards)。

「已連接」是狀態標籤，與工具按鈕同用白色表面及邊框、垂直置中，保留膠囊外形；不加點擊或製造保存成功語義。離線／檢查中仍沿原狀態色。

共用操作提示按語義分配：已保存用淡青色，明確失敗用淡珊瑚，待確認／unknown／衝突用黃色派生淺底及深警告字，處理中／說明保持安靜。狀態文案及原操作查核不因配色改變。

FE-W20 的 [首頁背景設定](APPEARANCE_HANDOFF.md) 復用 HomeBackground、現有 Paper 按鈕及 SVG 漸淡；本地換圖／恢復、桌面／手機同步預覽。沒有背景保存 API，原生 pickImage port 待接線，不與照顧照片／通知偏好混用。

登入沿 FE-W23 已還原的左介紹／右登入結構；FE-W38 桌面右欄 44%／至少 400、表單最寬 440。圖片沿原 0.55 透明度，以原圖 x=1552 作固定可見右邊界，排除太陽並保留指尖；按容器等比 cover、垂直置中，變窄只由左側裁切。FE-W24 在桌面介紹文字下面加半透明模糊面板；900 以下移除整個宣傳故事／插畫，只保留表單上方品牌及登入內容。[現行交接](HANDOFF.md#responsive-scroll)／[還原證據](HANDOFF.md#login-original-reset)。

## 待辦月曆與大量事項

待處理清單預設權威日期基準日起七天；較早未處理、待覆核、之後、全部及未知日期均有可發現的數目／入口。桌面月曆放在原待辦詳情區，選中待辦時由詳情取代，關閉還原同一月曆月份／日期，不另加一欄；窄屏月曆預設收起，點日期入口才展開；日期色點與文字標籤反映已載入事項，點日查看，同一已選日再點取消日期篩選且保留搜尋／其他條件，不從月曆新增另一套資料。搜尋與每頁十項只改顯示，原 cursor 續載與歷史分開；日期點涵蓋同 owner 已載入 pending，不受清單頁碼影響。未完成不因舊或多而自動消失，已完成仍只列最新十項。

## 成長常態報告與關注鏈

關注頁只追蹤同一事情的連續經過，相關處理結果留在鏈內；時間線由首個圓點下緣連起，首點上方及末點下方不伸出，單事件不畫延伸線。每條鏈有醒目的結束關注／歸檔主操作，先確認具名對象，歸檔後可撤銷並從歷史恢復；保留版本、權限及原操作恢復，不重建階段填表或不相關跳轉。

成長檔案直接看同源、持續更新的標準網頁報告，重點摘要及有依據的內容先出現，按有效資料分欄；年度／季度是次要翻閱入口。標題與重讀／歷史用緊湊可換行工具列，報告依據及來源標籤垂直對齊；補充資料與版本預設收合，輔助入口集中，避免每個按鈕獨佔一行。來源捲動工具按[輕量角色](#control-roles)處理。

PDF 僅導出當時版本，既有按用途選報告與內容的選項保持；PDF 不作頁面展示方案；報告以可讀的整理結果為主，不直接堆資料庫欄位或導出管理控制。現階段閱讀版型及正式生成的未驗／未接通範圍沿 [PLAN](PLAN.md#active)及[成長交接](GROWTH_HANDOFF.md#living-growth-archive)，不虛構發展評分、未觀察到的進步或已可下載 PDF。

### 按壓回饋的閱讀穩定性

可用控件按住時不降低整個控件的 opacity；文字、圖示、邊框及選中標記保持清楚。只依角色讓局部表面微幅變深：黃底、警告底與選中底保留各自語義，透明工具保持透明常態，不新增常駐框。disabled 的弱化與 busy、ripple、內容轉場屬不同狀態，不以全站 CSS 或重掛載來掩蓋。保留鍵盤 focus、觸控範圍、取消手勢及操作守衛；局部色彩斷言不能替代同版按住／放開的畫面檢查。
