## Function and boundaries

The added transport choice is only `date-list / original / original-row-fragment01`. It denotes the pinned historical **row fragment**, not an Original full version. Existing catalog acceptance/host checks and verified Tasks scope on both comparison frames remain required. The link opens a new tab with candidate text only. Native strict parsing and an empty receipt are required; the user must explicitly restore, enter selection mode and apply.

The native recipe/control/owner/data guards and storage policy are unchanged by this latest two-file native change. The Original assembly identity remains unavailable; the legacy fragment manifest digest is not evidence of complete assembly membership. Whole Original composition, global theme and first-phase acceptance remain unapproved.
