# Selection Workbench

The selection workbench (選配工作台) contains isolated, synthetic UI candidates for comparison.

- [preview12](versions/preview12/README.md): 13 interactive candidates, including the DV01 document version index.
- The module inventory contains 88 entries. It is an inventory, not a claim that all 88 modules are implemented or fully accepted.

This branch stores the complete static preview files. GitHub's file browser does not run the website. Download the complete branch and follow the version's HTTP serving instructions. This does not deploy or replace the existing preview site, production application, or earlier comparison-workbench branch.
