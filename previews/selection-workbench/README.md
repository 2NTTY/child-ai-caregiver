# Selection Workbench

The selection workbench (選配工作台) contains isolated, synthetic UI candidates for comparison.

- [preview15](versions/preview15/README.md): 16 interactive candidates across 15 modules, including NH01 personal message history and the separate N01 latest-five view.
- [preview12](versions/preview12/README.md): the preserved 13-candidate snapshot, including the DV01 document version index.
- The module inventory contains 88 entries. All 88 full semantic-acceptance gates remain pending. The 64 formal notification cases remain ALL_NOT_RUN; these are separate from preview15's 64 public reference URLs.

This branch stores complete static preview files. GitHub's file browser does not run the website. Download the complete branch and follow the selected version's HTTP serving instructions. This does not deploy or replace the existing preview site, production application, or earlier comparison-workbench branch. Preview12 remains unchanged.
