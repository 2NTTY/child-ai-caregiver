# AD01 建議核對與批准：選配候選

這是育伴港「選配工作台」的獨立合成候選，不是正式批准入口。所有人名、資料、資源識別與結果均為虛構。沒有外部圖片、字體、模型或資產，沒有帳戶、API、儲存或憑證操作。

- A「核對路徑」把同一提案分成對象、具體改動、可見範圍、明確決定四章。可直接跳章；閱讀和導航不會批准。
- B「影響展台」把完整內容並列，索引直接定位同頁區段。決定仍是獨立明確動作。
- 切換 A/B 共用同一份合成提案、原決定與收據。未知不自動變成失敗或成功；沒有預設共享確認。
- 操作後的「合成結果控制台」需要明確挑一個示例回應。它不是 Server，不會真的保存。
- 原略過在同版本已過期時，仍可在讀取後按原條件重試原略過。原接受過期不可沿此路重試。
- 收據只證明原資源及原版本的合成快照，不代表照護完成，也不代表資源目前狀態。已接受但沒有結果時，不能杜撰保存收據。

方法參考，只採資訊組織與操作界線，未複製程式、品牌、美術或第三方文案：

- GOV.UK Check answers: https://design-system.service.gov.uk/patterns/check-answers/
- UX Stack Exchange 最後一步預期討論: https://ux.stackexchange.com/questions/140293/what-to-do-when-a-seemingly-final-action-is-not-the-final-action
- Radix AlertDialog 原始碼的關閉與動作界線: https://github.com/radix-ui/primitives/blob/main/packages/react/alert-dialog/src/alert-dialog.tsx
- W3C G168 決定前核對: https://www.w3.org/WAI/WCAG22/Techniques/general/G168

以上研究是設計方法，不是本產品使用者研究或無障礙認證。合成模型與 JSDOM 驗證不代表正式 Owner、Provider、Server、原生裝置、真實鍵盤、觸控、螢幕閱讀器或像素驗收通過。此包尚待獨立實作覆核與正式接線評估。
