## Local viewing

Keep this entire version directory together. From this directory, run Python 3 on loopback:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory .
```

Open http://127.0.0.1:8000/index.html and stop with Ctrl+C. If port 8000 is occupied, use 8001 in both command and URL. Serve this version as its own HTTP document root, not the repository root. The server must return JavaScript MIME types for .js/.mjs and text/css for .css. GitHub file pages do not run the application; file:// is not a supported ES-module opening path.
