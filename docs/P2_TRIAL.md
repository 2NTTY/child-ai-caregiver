# P2 組員展示與回報

**目前未開放 P2 試玩；待 S17 部署及技術檢查通過後才執行。** 入口維持 https://ex-machina.eu.org，交付版本及實際結果記在 [P2 交付](P2_DELIVERY.md)。只用合成資料，不回傳密碼、bot token 或家庭正文。

本輪只補公開環境的通常流程，不重跑 S16 的完整矩陣。使用者已延後 Firefox 全套相容性；既有 Firefox 可用於一則公開 Push 的本人收取，內置瀏覽器可觀察一般功能，但不代替真通知服務。

## 同一合成孩子的兩段展示

1. 登入試玩帳號，建立一個專用合成孩子及一項已確認照護記錄。使用清楚的合成年齡和來源日期；例如九個月、已開始加固，用於查詢相關 FHS 片段。不要為展示修改既有孩子。
2. 若需要 Telegram，從「我的 Telegram 渠道」開始連結，本人到 bot 按 Start，再回網頁核對顯示身份及確認。不要按額外的一般測試按鈕；本輪將以已批准的照護提示核對 webhook。Web Push 在本人現有 Firefox 訂閱公開網站，亦不連續按測試。
3. **展示 A：**在 AI 聊天提出一個含知識及任務的要求，例如查閱這位合成孩子的已確認資料，引用香港官方加固資料，並提出一項家長選定時間的觀察／安排提醒。查看「來源與待確認事項」、實際工具及任務結果；有候選時明確確認，AI 推斷不能冒充已確認事實。若需要改期，用既有任務入口，不再多問一次模型。
4. 只對該合成任務設定本人的接收渠道及聯絡授權，核對對象、用途及內容。示範可選數分鐘後的時間；若落在安靜時段，只在使用者明確選擇的預約例外下處理，不改伺服器時鐘或繞過偏好。
5. **展示 B：**關閉網站分頁、保留接收通知的瀏覽器運行；由正常 Server worker 處理到期事件。本人確認收到通知；Telegram 的「收到提示」只記錄收到。重開網站，在背景處理結果／任務台帳核對，再明確完成合成事項，確認不再催辦。
6. 查看同一孩子的照片、分享／私人來源及摘要入口是否可操作；沿用已有本機模型證據，不再要求照片或分享文字做 AI 提取。一份合成照片供 Linux 附件／配對備份核對，待主聊天核對備份後才對本次新增的合成資料作明確清理，撤銷本次專用授權／訂閱；保留原資料。功能完整清單與 API 對照見 [UI 交接](P2_UI_HANDOFF.md)。

整段示範的模型／通知上限及失敗停止條件按 [本次驗收範圍](P2_DELIVERY.md#最小公開驗收與展示)。遇到失敗或結果 unknown，記下操作與畫面文字，不連續重試、不另建相同任務；由主聊天核對台帳。

## 實際回報

請由實際操作的組員提供以下資料；未操作寫「未執行」，不要按預期代填：

- 操作人、日期、瀏覽器及畫面所用版本。
- 展示 A：記錄／引用是否正確；候選確認與任務結果為「通過／失敗／未執行」。
- 展示 B：關頁後通知是否真正收到；收到與完成是否分開；完成後是否停止催辦。
- 公開 Push／Telegram 綁定及 webhook 的實際結果；未收到不因服務接受而寫通過。
- 原資料仍可讀、重新登入或權限切換有否問題，以及實際遇到的錯誤。

本頁是操作指引，尚不是組員已完成、臨床有效性或新前端設計獲確認的證據。
