4. 只對該合成任務設定本人的接收渠道及聯絡授權，核對對象、用途及內容。示範可選數分鐘後的時間；若落在安靜時段，只在使用者明確選擇的預約例外下處理，不改伺服器時鐘或繞過偏好。

6. 查看同一孩子的照片、分享／私人來源及摘要入口是否可操作；沿用已有本機模型證據，不再要求照片或分享文字做 AI 提取。一份合成照片供 Linux 附件／配對備份核對，待主聊天核對備份後才對本次新增的合成資料作明確清理，撤銷本次專用授權／訂閱；保留原資料。功能完整清單與 API 對照見 [UI 交接](P2_UI_HANDOFF.md)。
