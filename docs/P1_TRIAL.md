# P1 組員獨立試玩

狀態：尚未部署，尚無試玩結果；正式 URL、版本及環境驗收由 S17 完成後填入。不需要重新設計 UI，也不使用真實孩子資料。

## 操作範圍

1. 組員自行從交付 HTTPS URL 開啟 Web，用專用測試電郵註冊並登入；不要在聊天貼密碼。
2. 建立一個合成孩子，輸入一筆含空格、換行及「大約」的照護文字，核對確認畫面後保存；讀回原文。
3. 關閉頁面後重新開啟、登入，確認同一孩子與記錄仍在。
4. 發送一個合成照護問題，確認 user 原文先保存，再顯示 Gemini 回覆；用一次追問核對近期上下文。只做這兩次呼叫；失敗記下時間及畫面狀態，不連續重試。回覆是一般協助，不能代替醫護判斷。
5. 斷線後輸入未提交文字，核對沒有顯示已保存；恢復連線後由自己重試。關閉／刷新前留意未提交內容提示。
6. 登出並改用另一個測試帳號登入，確認沒有第一個帳號的孩子、記錄、私人聊天或草稿。
7. 如試玩刪除，只建立及刪除新的合成孩子；核對二次確認的對象，確認其他孩子仍在。不要刪已有共用測試資料。

## 結果回報

由實際操作的另一位組員填寫：日期、測試版本／URL、瀏覽器、上述步驟的通過／失敗／未執行、卡住的步驟及簡短重現方法。不要貼密碼、cookies、key、私人正文或真實家庭資料。未試的項目寫「未執行」，不要預填通過。

兩次模型呼叫屬正式試玩範圍，需在交付時與部署／模型成本一起批准。只有收到組員實際回報並處理必要問題，才可把 S17／P1 標為完成。
