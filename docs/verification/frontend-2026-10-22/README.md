## 剩餘接口與環境限制

- **後端程式不等於正式接通**：消息後端程式已隨 24c 提交至同一 PR，但未部署或啟用正式服務，功能預設關閉。需部署負責人先完成所有服務／背景工作節點的相容部署、確認 4 個 Firestore 索引 ready，再第二階段啟用；回滾也受相容版本下限限制。真實接口、通知服務、索引併發及正式啟用尚未驗證。
- **公開站仍為合成預覽**：寫入回 405；慢讀、503、403 等故障由隔離 QA 合成傳輸驗證。未調真模型、傳真實家庭資料或發送真消息。搜尋只限已載入消息，不宣稱補齊舊版未保存正文或帳戶驗證郵件。
- **基線未全綠**：前端 `ContactConsentCard.tsx` 仍有 2 個既有型別錯誤；全專案型別檢查仍為既有 90 個診斷、0 新增。既有恢復／設定測試失敗也未宣稱修復。
- **部分操作只有程式測試**：多提示同時顯示、背景導航保護、延遲批准／停用、晚回身份請求、慢讀中切孩子與退出後再切孩子的組合，CUA 未全部完成；不能以程式測試替代畫面通過。
- **裝置與無障礙有限**：未驗 Firefox、原生 Android／iOS、語音螢幕閱讀器；只做鍵盤、焦點、語義、對比的定點檢查。帳戶最終密碼／固定文字刪除畫面未在這套 QA 到達，不宣稱全面無障礙或全站全組合通過。

**文件包封存狀態**：產品提交已完成；本驗收文件包在封存時仍為準備上傳，未宣稱文件包已進入 PR。公開站小範圍檢查不擴大原驗收矩陣。
