## 修改清單

1. **核對提案卡**：先看正文，再開所選提案的原內容；不混入同次運行的其他提案，異常／未知結果保留原恢復路徑。
2. **數量及分頁**：清楚顯示 `N`／`N+`；載入、失敗、未讀不假裝成零筆。背景更新按已讀頁數核對，完整成功才替換，不用第一頁覆蓋已讀第二頁。
3. **窄屏工具列**：整理待核對、已存記錄與手動新增，保留操作權限、鍵盤啟動及關閉回焦點。

- **後端未視為已部署**：預覽是明示合成唯讀，不證明正式 API、模型、通知或家庭資料已接通。先前消息後端程式已交付，但正式啟用預設關閉，仍需部署負責人確認全 fleet 與 4 個索引 ready，再分階段啟用。

- **非全裝置驗證**：主要為雲端 Chrome 的 CSS viewport／iframe，部分為原生瀏覽器視窗截圖，不是原生 Android／iOS；Firefox、語音播放及全類別全新 26d 故障／分頁矩陣未驗。部分舊 1440 圖及本輪 26d 1440 圖僅為可見區段，不充作全寬證據。
- **環境故障保留**：歷史 renderer code 9、一次建置 Killed 137 及 tab 消失原因未證實，不歸因於產品或記憶體。26d 兩條重驗未遇到這些故障，不推論全站穩定或零 bug。
