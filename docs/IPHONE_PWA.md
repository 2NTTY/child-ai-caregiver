# iPhone 主畫面試用

1. 用 iPhone 的 Safari 開啟 [育有方](https://ex-machina.eu.org/)，按「分享」→「加入主畫面」→「加入」。如有「作為網頁 App 開啟」，保持開啟。之後從主畫面的「育有方」圖示進入，以原帳戶登入並選擇孩子。
2. 在「設定」的通知頁開啟這部裝置的瀏覽器通知。先選「只顯示有新訊息」或「顯示訊息開首」，再按確認及 iOS 的「允許」。鎖屏預覽可隨時改回通用提示，亦可停用這個安裝的聊天通知。iPhone 需要 iOS 16.4 或以上及網絡連線。
3. 收到助手通知後點一下，核對原訊息並在同一聊天回覆。若提示登入，請用原帳戶。鎖屏時能看到多少內容取決於這部 iPhone 的通知預覽及「專注模式」。
4. 在助手輸入列可拍照、從相簿選相、錄音試聽或從「檔案」選取附件。內容先加入目前草稿，按送出才上傳。若 Safari 無法解碼 HEIC，請選擇 JPEG 或 PNG。

**一次真機核對**　示範帳戶開啟通知後，關閉主畫面版並鎖屏。在另一部裝置的 [Web 管理後台](https://ex-machina.eu.org/admin) 按一次「立即示範主動通知」，保留原收據。記下 iOS 版本、所選預覽、實收顯示，以及點開後的孩子／原訊息是否相符。在 iPhone 回一句，再由 Web 讀回。最後在 iPhone 關閉聊天通知，核對該安裝的設定已保存。媒體各核一次，完整送出只需一張測試照片，再由 Web 讀回。
