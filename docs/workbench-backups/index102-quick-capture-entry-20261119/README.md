## 手機首頁快捷記錄：不拖曳也能選文字、語音或文件嗎？

在手機首頁、已選孩子且可開草稿時，現版輕點走拍照，長按放手後仍可點選其他輸入；支援的鍵盤路徑也可展開及取消。選文字會開草稿，選語音可能開始錄音，兩者都不等於送出。目前正式接點的文件選項顯示「正在接線」，不要當成已能使用。這題比較如何找到入口，不是錄完後的語音草稿，也不是上傳中斷重試。
