## Checks and backup scope

The same 69 images were viewed in the single reader on desktop and in a controlled 390 CSS-pixel frame: 138 checked visits. The two choices appear side by side on the wide layout and stacked on narrow layouts. No global horizontal overflow in the final tested groups/variants. Explicit choose, replace, withdraw and cross-topic list operations were checked; browsing alone left the list empty. Copy and manual text selection were tested, as were keyboard page navigation, the original-size image scroller and blank choices on reload. No storage or automatic submission; no source application code ran. This was not a physical-device or upstream acceptance test. No actual selections are recorded in this index.

Two private artifacts were restored and matched byte for byte:
- self-contained reader: 15471118 bytes, SHA-256 4fe63727e2da4e06066bc7e44616ac9b158eea8a6f541e55cb15bf3e061d4bb7
- verification records, 8 ZIP entries: 21883 bytes, SHA-256 c28f688d3174b21b1d4e213a433a5aadb4be4f1b3d33e2dda698378ed466165c

The standalone reader is sufficient for the 16 included topics; the audit ZIP alone cannot render them. This branch contains only this authored text index; it does not contain the reader, pictures, source payloads, private access links or credentials, and cannot independently recreate the preview. Earlier workbench branches and the main product are unchanged by this index.
