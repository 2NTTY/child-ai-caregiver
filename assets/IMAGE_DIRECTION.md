# 育伴港生成插畫方向

這套六張插畫供未來網站、簡報及文章重用，延伸「港灣環抱與一點指引光」的品牌敘事。它們是虛構家庭的生成插畫，不是家庭個案、產品截圖或功能已交付的證據。本文件及 [image-prompts.json](image-prompts.json) 定義提示詞；六張 PNG 已於 2026-09-22 由內置 ImageGen 生成並逐張目視 review，見 [成品記錄](images/manifest.json)。

## 共用畫風

採用溫暖、精緻的 editorial 插畫，以薄水粉層次、淡水彩暈染及細緻啞面紙紋增加質感。保留現有 SVG 的圓潤輪廓、克制留白與清楚主次，同時加入柔和體積、衣料及家居細節；人物比例自然，表情親切但不誇張，適合成年照顧者閱讀。

色彩沿用 `paper #FAF7EF`、`sage #DDE8DB`、`teal #287568`、`ink #203E3A`、`amber #D99A3D`、`coral #C86D52`。以紙白和灰綠作底，青綠及墨綠組織畫面，琥珀光與珊瑚色作少量暖點；容許同系顏色的明暗混色。指引光可化為晨光、窗光或枱燈，不必每張都出現星形符號。

家居場景以香港日常小型住宅為基礎：用途重疊的餐桌、小型收納、自然窗光及少量生活物件。品牌主圖則採普通社區海旁，讓港灣曲線環抱人物；不依靠旅遊地標、豪宅陳設或霓虹夜景表達香港。

## 敘事與使用界線

- 畫面主角始終是孩子與實際照顧的成人。成人清楚在場、投入陪伴；AI 不以機械人、浮動角色或代替看顧者的方式出現。
- 交接呈現可信、平等的共同照顧，不用制服或主僕姿態區分角色；課後場景呈現家庭節奏，不暗示分數或成效保證。
- 赴約準備只呈現回想、整理與待問事項，不畫診斷結果、藥物、醫療標誌或臨床器具。
- 全部插畫不含任何文字、偽文字、字母、數字、logo、QR code 或水印。筆記、書本及書包不帶標記；共讀書頁只用無字圖畫。
- 手機只在日常記錄場景作次要物件，螢幕朝內，不繪製可識別 UI。標題、標誌及功能說明由網站或 PPT 另外排版，保留可修改性。

## 提示詞與驗收

[image-prompts.json](image-prompts.json) 的每個 `prompt` 均為可獨立直接送入內置 ImageGen 的完整英文提示詞，已包括 `Use case: illustration-story`、場景、構圖、材質、色系及限制；毋須另外拼接 `style`。`style` 是整套共通方向，`use` 與 `alt` 供香港繁體中文的資產管理及後續整合使用。

生成後逐張目視確認人物數目及大致年齡、手部與姿勢、成人照顧關係、場景差異、紙紋與色系、預定留白，以及有沒有明顯意外文字或 UI。`alt` 已按選定圖片核對；未來重新生圖仍須重查。原始提示詞不保證每次生成相同像素或人物，既有 SVG 沒有因此修改。
